Raspberry Pi Desktop

The Foundation's 32-bit x86 edition of the Pi's desktop, booting for real in this tab.

Nothing starts until you press Start: each boot streams about 3.4 GB (≈430 range requests) from the shared image proxy.

A cold boot prints kernel messages for a few minutes before the system is up.
