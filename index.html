Serial console

Every byte the guest writes to its first serial port, captured from the emulator as it arrives. The Raspberry Pi ISO is booted with console=ttyS0 and journald's console forwarding, so its kernel messages and each service's own output — LightDM's included — appear here even while X, or a greeter that never paints, holds the screen. Other images only print here if their own boot command line sets up a serial console.
