Raspberry Pi Desktop

The Foundation's 32-bit x86 edition of the Pi's desktop, booting for real in this tab.

  1. Get the ISO below: the 2022-07-01 i386 build, 3.4 GB. The October 2026 build is amd64-only and cannot run on this CPU.
  2. Choose the file, or drop it anywhere on this page. It is never copied into memory: the emulator reads 512 KiB slices from it as the guest asks.
  3. Wait. A cold boot prints kernel messages for a few minutes before the system is up.
