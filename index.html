Raspberry Pi Desktop

The Foundation's 32-bit x86 edition of the Pi's desktop, booting for real in this tab.

  1. Download the 2022-07-01 i386 ISO (3.4 GB). The 2026 build is amd64-only and cannot run here.
  2. Choose it below. It is never copied into memory: the emulator reads 512 KiB slices from the file as the guest needs them.
  3. Wait. A cold boot prints kernel messages for a few minutes before the system is up.
